Privacy Policy

Last updated: 28 April 2026

This Privacy Policy describes how the Jinny Lee Real Estate Social Media Manager ("the App") handles information. The App is a private automation tool used solely by Jinny Lee Real Estate to publish content to social media platforms.

1. Who Uses This App

This App is used exclusively by Jinny Lee Real Estate. It is not a public application and is not accessible to or used by third-party individuals or businesses.

2. What Data Is Collected

The App does not collect personal data from any third parties. The only data processed is:

  • Social media access tokens belonging to the Jinny Lee Real Estate business account
  • Publicly available news articles used to generate social media content
  • Social media post metadata (post IDs, timestamps) for internal record keeping

3. How Data Is Used

Data is used solely to:

  • Authenticate with social media platform APIs (TikTok, Facebook, Instagram)
  • Publish pre-generated content to the Jinny Lee Real Estate social media accounts
  • Maintain posting history to avoid duplicate content

4. Data Sharing

No data is shared with any third parties. Access tokens are stored securely as encrypted secrets in a private GitHub repository and are never exposed publicly.

5. Data Retention

Post history records are retained for up to 14 days for deduplication purposes and then automatically deleted.

6. TikTok Data

The App uses the TikTok Content Posting API solely to publish video content to the Jinny Lee Real Estate TikTok account. No TikTok user data is collected, stored, or shared. The App complies with TikTok's Platform Policy and Developer Terms of Service.

7. Contact

For any privacy-related questions, please contact Jinny Lee Real Estate via rwbotany.co.nz.
